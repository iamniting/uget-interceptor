# uGet Download Interceptor

Chrome Manifest V3 extension that intercepts Chrome downloads and sends them to uGet through `uget-integrator`.

## Install

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder.

Make sure `uget-integrator` is installed and the native messaging host `com.ugetdm.chrome` is registered.
